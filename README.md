# 主日學教學輔助工具箱 (Sunday School Teaching AidKit 備課資料)

本平台專為基督教兒童主日學老師量身打造，完整收錄 **2026 年第三季與第四季共 26 課** 教材與備課資料。每個 PPT 均完整對應一個**獨立專屬教學頁面**，並配備投影片逐頁對齊駕駛艙、講員逐字稿與五大多元輔助教材庫。

🌐 **正式線上平台首頁**：[https://waatax.github.io/SS/](https://waatax.github.io/SS/)

---

## 🌟 深度優化升級亮點（7 次迭代精華）

1. **每個 PPT 獨立專屬教學頁面**：
   - 26 個完整獨立教學頁面（`lessons/2026-q3-01.html` ~ `lessons/2026-q4-13.html`），可作為個別課堂書籤與專用投影頁。
2. **投影片逐頁精確對齊與講稿駕駛艙 (Slide Companion Cockpit)**：
   - 提取全套 340 幅高解析度教學插畫與場景圖。
   - 逐頁標註：原文字稿、老師口頭台詞逐字稿（怎麼說）、課堂即時發問點（問什麼）、建議停留時間。
3. **五大多元輔助教材庫 (Auxiliary Teaching Materials)**：
   - 🎭 **聖經角色扮演短劇劇本**：3~5分鐘短劇，角色名單、對白台詞與動作指引。
   - 🏠 **家庭共讀與親子聯絡卡**：本週金句、餐桌話題、全家晚禱詞，一鍵列印帶回家。
   - 📜 **聖經原文關鍵字微課堂**：希伯來文 / 希臘文字義深度解碼（如 Hesed、Natan、Shema、Purim）。
   - 🚨 **課堂突發脫序應變 SOP**：校長親授課室秩序急救法（爭搶、哭鬧、走神、分心應對）。
   - 💭 **孩子最常問的尖銳問題**：傳道人解惑對話錄，破除信仰教條化。
4. **六大跨領域專家團隊指導**：
   - 校長 50 分鐘節奏時間軸、傳道人說故事 Hook、牧師基督中心福音透鏡、教育專家 5E 教學模式、心理學家情緒溫度計。
5. **課堂數位工具箱**：
   - 浮動課堂計時器、金句記憶小工具（一鍵挖空/遮蔽）、低年級互動選擇題（動效與音效判定）、高年級開放討論題、大螢幕投影演講模式、一鍵列印學習單與備課手冊。
