# 基督教主日學老師教學輔助平台 (SS Teacher's Cockpit)

本平台專為基督教兒童主日學老師量身打造，完整收錄 **2026 年第三季與第四季共 26 課** 教材資料。跳脫單純的 PPT 簡報投影片文字，整合跨領域專家團隊智慧，建構極致實用的備課與課堂教學輔助系統。

🌐 **線上網站**：[https://waatax.github.io/SS/](https://waatax.github.io/SS/)

---

## 👥 六大專家團隊深度賦能體系

1. **🏫 資深有愛心、風趣的校長 (Principal Barnabas)**
   - 5分鐘快速備課清單
   - 50分鐘精準課堂節奏配比時間軸
   - 課堂躁動幽默應對話術與常規口令
2. **🔥 主日學長大的熱血傳道人 (Pastor Timothy)**
   - 懸念吸睛說故事 Hook（開場破題法）
   - 當代兒童校園人際與心靈真實掙扎對接
3. **📖 資深牧師 (Senior Pastor John)**
   - 聖經神學焦點與救贖歷史宏觀
   - 福音與基督中心透鏡（指向十字架與恩典）
   - 給主日學老師的課前靈修守望
4. **🧠 現代教育專家 (Dr. Bloom-Dewey)**
   - 布魯姆認知分層檢核（記憶、理解、應用、評估）
   - 5E 教學循環（Engage, Explore, Explain, Elaborate, Evaluate）
   - 多元智能學習活動配搭
5. **🧸 兒童發展與心理學專家 (Dr. Piaget-Erikson)**
   - 具體運思期（低年級）vs 形式運思期（高年級）認知特質
   - 教室無嘲諷心理安全感營造與同理心引導
6. **💻 網頁大師 & UI/UX 專家 (Lead UI/UX Architect)**
   - 響應式手機/平板/桌機/投影機跨載具設計
   - 課堂即時倒數計時器（附提示鈴聲）
   - 金句記憶小工具（一鍵遮蔽/挖空複習）
   - 低年級互動選擇題（點擊即時反饋動效與音效）
   - 一鍵切換投影大螢幕專注演講模式
   - 一鍵列印學生學習單與教師備課手冊
